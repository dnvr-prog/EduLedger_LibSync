EduLedger: LibSync

Digital Library Records System

EduLedger: LibSync is a web-based library management system designed to help organize student records, book information, and library borrowing transactions.

Features

- Admin and student login
- Student registration and record management
- Book record management
- Book borrowing and return tracking
- Search and view library records
- Borrowing history and overdue monitoring
- Dashboard statistics and reports

Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

Local Setup

1. Install XAMPP.
2. Copy the project folder into "htdocs".
3. Start Apache and MySQL.
4. Create the required database in phpMyAdmin.
5. Import a sanitized database SQL file, if provided.
6. Configure the local database connection.
7. Open the project through "http://localhost/your-project-folder/".

Project Status

Developed as a student project to demonstrate web development and database management skills.

Security Notice

This repository should not contain real passwords, private credentials, or personal student information.
